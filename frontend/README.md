# Frontend – Real-Time Shipment Tracking Portal

React-based dashboard (**Week 4**). Consumes backend APIs and **Week 3** WebSocket for live tracking.

## Planned (Week 4)

- **Tracking page:** Enter tracking ID → view shipment on map
- **Live updates:** WebSocket (STOMP, from Week 3 backend) to show real-time GPS on map (e.g. Leaflet)
- **Auth:** Optional login with JWT for shipper/carrier flows

## Setup (when app is created)

```bash
cd frontend
npm install
npm run dev
```

Backend API: `http://localhost:8080`
